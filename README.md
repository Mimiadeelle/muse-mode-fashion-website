# MUSE MODE — Fashion Brand Website

A responsive fashion-brand website built as an individual HTML, CSS and JavaScript project.

## Pages/sections
- Home: brand introduction and navigation
- About: background, mission and brand values
- Collections: three product/service categories
- Contact: sample contact details and validated contact form

## Technologies demonstrated
- **HTML5:** semantic elements, headings, links, images and form controls.
- **CSS3:** external stylesheet, selectors, spacing, typography, positioning and responsive media queries.
- **Flexbox:** navigation, buttons and alignment of page elements.
- **CSS Grid:** hero layout, product cards and content sections.
- **JavaScript:** mobile navigation interaction, event handling and contact-form validation.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Deployment
This is a static website. It can be deployed by importing the GitHub repository into Netlify or Render as a static site. Publish the project root directory.

## Important notes
- The email and phone number shown on the website are clearly labelled sample details. Replace them with approved contact details before public use.
- The contact form performs front-end validation only. It does not send or store messages because no backend or form-submission service is connected.
- The hero image is loaded from Unsplash and requires an internet connection.


## Contact details
